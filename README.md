# Game3121 Assignment 1

**Two Unity Create-with-Code challenges in one coursework repo** (plane flight challenge + dog-catch ball challenge), built as a team submission.

---

## Status

Educational assignment. Multiple contributors (primarily Hakan Özcan, with additional commits by Melih Burak). Includes recording-related commits.

## Tech stack

| Area | What it uses |
|---|---|
| Engine | Unity (challenge project layout under `Part1/` and `Part2/`) |
| Language | **C#** |

## What's in the project

| Part | Focus | Key scripts |
|---|---|---|
| `Part1/` | Plane challenge | `FollowPlayerX.cs`, `PlayerControllerX.cs`, `PropellerSpin.cs`, `Obstacle.cs` |
| `Part2/` | Dog / ball challenge | `PlayerControllerX.cs`, `SpawnManagerX.cs`, `DetectCollisionsX.cs`, `DestroyOutOfBoundsX.cs`, `MoveForwardX.cs` |

## About this repository

Team coursework. Not a production game.
